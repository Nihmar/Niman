Wikilink suggester

While a wikilink is being typed, a small panel lists what can go there and filters as the text grows. 1 to 4 are the states the issue describes; 5 is a probe for the book forms. Each is drawn at window size over the note, then again larger, because the panel is too small to judge at arm's length.

The panel is drawn in the live editor, where the caret is and where the link is written. It sits under the caret's own rectangle — the same seam the touch toolbar uses — and never in the note's text.

Rows read name then the folder, dimmed, so a link can name the right one. A row found through an alias carries the alias: alias md. The matched run is in bold: Links, Dead links. Keys: ↑↓ move, ↵ or Tab insert, Esc close.
