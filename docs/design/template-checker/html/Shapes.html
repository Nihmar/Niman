Template checker — the two shapes

One template note, drawn twice, with the same three problems in it. Shape (i) marks the offending span and offers the fix where the mistake is; Shape (ii) counts the problems in a quiet line and lists them. Both mark the same text, so the two can be compared by looking rather than by arguing.

Points at the text. The wavy line sits under the exact span and moves with it as the line is edited; the hint appears on the span, so the message and its fix are where the mistake is. The no-fix case says so plainly: the hint carries only Dismiss, no button that would rewrite text the author did not mean. Cost: only the problems on screen are marked — one scrolled away is invisible until it comes back — and the hint needs a hover, or a tap on touch. Two hints are drawn open here so both the fix and the no-fix shape can be seen; in use only one is open at a time.

Lists everything at once, and survives scrolling. The count is a one-line summary that reads the same however far the note is scrolled; the list it opens is the whole set, one row per problem, each carrying its own fix or its own “no fix offered”. Cost: it does not point at the text — the span is read in the list and then hunted for in the note — and an open list pushes the note down. Drawn here at the top of the note; it could instead sit in the bottom status row, where it would cost the note nothing and stay put while the text scrolls under it.

Mockups, not screenshots of the app: everything here is HTML drawn to look like Niman, using the palette from lib/src/ui/theme/niman.dart. Where a mockup and the app disagree, the app ships.
