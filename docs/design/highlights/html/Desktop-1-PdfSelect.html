2.1 Seven ideals for local-first software

We believe that data ownership and real-time collaboration are not at odds with each other. It is possible to create software that has all the advantages of cloud apps, while also allowing users to retain full ownership of the data they create.

In this section we propose seven ideals for local-first software: properties that we believe such software should have. The availability of another computer should never prevent you from working. We call this the offline ideal.

Conflicts should be shown to the user as a choice, not as an error, and the software should make it easy to pick one version or to merge both.

The cloud should be a place to back up and to share data, not the only place where the data lives.
