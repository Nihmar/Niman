Local-first software
2.1 Seven ideals

It is possible to create software that has all the advantages of cloud apps, while also allowing users to retain full ownership of the data.

In this section we propose seven ideals. The availability of another computer should never prevent you from working.

Conflicts should be shown to the user as a choice, not as an error, and the software should make it easy to pick one.

The cloud should be a place to back up and to share data, not the only place where the data lives.
