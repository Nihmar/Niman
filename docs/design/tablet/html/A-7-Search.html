1.2 Subspaces and linear dependence

Once a coordinate system is chosen, the geometric vectors of space can be identified with ℝ³, and the operations between vectors become operations on triples.

Definition 1.2.1. A non-empty set W of ℝ³ is a subspace if it is closed under addition and under multiplication by a scalar.

⟨v⟩ = { αv | α ∈ ℝ }

The set {0} and ℝ³ itself are the trivial subspaces; the plane x₃ = 0 is a subspace that can be identified with ℝ².
