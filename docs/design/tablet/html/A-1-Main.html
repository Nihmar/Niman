1.2 Subspaces and linear dependence

Once a coordinate system is chosen, the geometric vectors of space can be identified with ℝ³, and the operations between vectors become operations on triples, done component by component.

Definition 1.2.1. A non-empty subset W of ℝ³ is a subspace if it is closed under addition and under multiplication by a scalar.

⟨v⟩ = { αv | α ∈ ℝ }

See [[1.3 Bases and dimension]] for how a subspace is described by as few vectors as possible.
