Frontmatter

The same note, three states, drawn to be looked at rather than argued about. A and B answer “where do the fields live?” — above the note in the read view, or inline at the top of the live editor, where the writing happens. C is the state that decides whether the panel is safe: a frontmatter the parser refuses.

Every state keeps the raw YAML one toggle away, and the file stays the only source of truth: a field edit is one edit, one undo step, one write.
