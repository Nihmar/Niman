Copist — WYSIWYG editor mockups

Visual target for the WYSIWYG editor plan (plan/m-wysiwyg-editor.md). Two per-library settings drive every screen: Editor (Markdown source / WYSIWYG) and Preview (on / off). The WYSIWYG editor is never side by side with the preview. Use the segmented controls to switch modes; the highlights mark the controls that are added, moved or hidden.

Android — Settings phone

The two new rows live under Editor. Editor opens the picker (source / WYSIWYG); Preview is a plain switch. The split-ratio row only exists when the preview can actually split, so it disappears in WYSIWYG and when the preview is off.

Why two settings, not one. The editor and the preview are independent: you can keep the source editor and turn the preview off, or write in WYSIWYG without a preview. WYSIWYG + preview is allowed but switch only — the two are never side by side.

Android — Editor phone

On a phone the source editor and the preview are already one pane behind the eye. WYSIWYG replaces the source pane and its Markdown toolbar with a Quill editor: the eye still flips to the read-only preview, and it is never split. Preview off removes the eye entirely; the editor keeps its own toolbar.

What changes here. The Markdown toolbar is gone in WYSIWYG (the Quill bar takes its place), the source toolbar comes back with Preview off, and the split divider never appears on a phone. Table, math and footnote blocks are the shaded boxes: read-only, written back byte for byte.

Desktop — Editor wide

On desktop the source editor and the preview share the window with a draggable divider. Selecting WYSIWYG removes the split (the layout menu disappears), leaving the full-width Quill surface plus the eye switch to the read-only preview. Preview off removes both controls and gives the whole window to the editor.
